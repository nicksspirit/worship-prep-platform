Store one Mermaid-backed Markdown file per n8n workflow in this directory.

## Naming
- Use the workflow slug in lowercase kebab-case, for example `worship-prep-platform-dev.md`.

## Expectations
- Keep the diagram synced with the latest workflow architecture, node flow, and prompt-bearing AI nodes.
- Update the diagram whenever the workflow changes, even when the prompt text does not.
- If the workflow structure cannot be verified directly, keep the known nodes documented and mark unverified areas clearly instead of inventing details.
